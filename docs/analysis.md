# 読解プリント作成サイト 設計用 資料分析

公立高校入試・国語の「文章読解」の前段階トレーニング（問題を解く前に身につけるべき見方・確認事項）のプリントを作るサイトのため、提供資料（PDF 70ページ・写真121枚）を分析したもの。

---

## 1. 資料の内訳

| 記号 | 資料 | 位置づけ | 主な中身 |
|---|---|---|---|
| **A** | ふくしま式「本当の国語力」が身につく問題集（パートⅠ〜Ⅴ） | **論理の3つの関係を単文〜短文で鍛える** | 言いかえる力（同等関係）／くらべる力（対比関係）／くらべる力＋言いかえる力／たどる力（因果関係）／総合テスト |
| **B** | 中1国語 教科書準拠ワーク（光村） | 教科書の「情報整理」「思考のレッスン」の基礎用語の確認 | 比較・分類、原因と結果、具体化・抽象化、根拠の吟味、情報の信頼性、指示する語句・接続する語句、文学的／説明的文章の読み方 |
| **C** | 高校入試 読解の「基本ルール」型の参考書（セクション1〜3） | **読解の大原則＋文種ごとの読み方** | はじめに（答えは文章中にある）、第1章 文脈力（指示語・接続語）、第2章 論説文（主張と理由・具体例・対比・反対意見・段落要点）、第3章 小説・随筆（客観的に心情を読む） |

**4冊の関係（重要）**
A（関係を見抜く思考の型）→ C（その型を文章読解の「ルール」として使う）→ D（入試の設問形式ごとの手順に落とし込む）という順に、**同じ考え方が粒度を変えて繰り返し出てくる**。B はその基礎用語（抽象・具体、根拠、原因・結果など）を教科書の言葉で確認するもの。サイトのカリキュラムもこの順番が自然。

## 2. 「解く前に身につけるべきこと」── スキルマップ

資料に共通して出てくる考え方を、プリントの**スキルタグ**として使える単位に分けた。

### S0 読解の大原則（C「はじめに」）
- **すべての解答は文章のどこかに書かれている**。書かれていないことを答えたら✗。
- 問われているのは「何を感じたか」ではなく**「何が書かれているか」**（客観性）。
- 選択肢は、本文に書かれていない要素が**1か所でもあれば✗**。（例：「人間は優秀な動物である」は本文にないので✗）

### S1 同等関係＝言いかえ（A パートⅠ、B 具体化・抽象化）
- 〈具体〉⇔〈抽象〉。「つまり」で抽象化、「たとえば」で具体化。
- **マトリョーシカ方式**：外側ほど意味が広い（抽象的）、内側ほど意味が狭い（具体的）。鉛筆 ⊂ 筆記用具 ⊂ 文房具 ⊂ 道具。
- 抽象化は「**共通点だけを残して、具体的な部分を捨てる**」こと。
- **2ステップ抽象化**：具体がいくつかのグループに分かれているときは、ステップ1でグループごとにまとめ、ステップ2でさらにまとめる。（例：アイスとチーズケーキ／杏仁豆腐 → デザートを食べた）
- 文章レベル：例示の段落を見つけて、その段落が言いかえている抽象的な一文を特定する。

### S2 対比関係（A パートⅡ・Ⅲ、C 対比）
- 対比の言葉は**反対語**（大きい⇔小さい）または**否定表現**（大きい⇔大きくない）。
- **観点の統一**：「昼は明るいが、夜は暗い」の観点は「明るさ」。「昼は楽しいが、夜は暗い」は観点がずれていて成り立たない。
- **見えていない観点を見つける**：「キリンよりハムスターが好き」→ 観点は大きさ（大⇔小）なのか、首の長さなのか。
- **書かれていない片側を補う**：筆者が「造花のよさ」だけを書いていても、裏には「生花の悪いところ」がある（A パートⅢ-15）。
- 文章の型：「Aは〜。一方、Bは〜。」→ 筆者の主張はどちらの側にあるのか。

### S3 因果関係（A パートⅣ、B 原因と結果、C 主張と理由）
- 「だから」（原因→結果）⇔「なぜなら」（結果→原因）を入れ替えて言えること。
- 因果が成り立つ基準は「**なるほどと思えるか（10人中8人が納得するか）**」＝客観性。
- **ア→イ→ウ のイを補う**：「寝坊した→遅刻した」の間に隠れたつなぎ（間に合う電車に乗れなかった）を入れる。省略された前提を言葉にする練習。
- **ア＋イ→ウ**：理由が二つ重なって結論になる型。「アだから、イという状況で、ウ」。
- 理由を答えるときは文末を「〜から。」「〜ので、〜から。」の形にそろえる。
- B：「原因と結果に飛躍はないか」「偶然や共通の別の原因ではないか」を確かめる。

### S4 指示語（C 第1章、D UNIT9、B）
- 指示語は「同じことを繰り返さないため」に使われる言葉。
- 指示内容は**まず直前から探す**。前になければ後ろを探す。
- 見つけた内容を**指示語の位置に当てはめて、意味が通るか確かめる**。
- 傍線部の**あとの内容**（「〜に近いものが残されている」など）を手がかりにする。

### S5 接続語（C 第1章、D UNIT10、B）
- 種類（C の一覧）：順接／逆接／補足説明／イコール（言いかえ・要約）／理由／添加／並列／対比／比較／例示／話題の転換。
- 空欄補充の解き方：**空欄の前の内容をおさえる → 後の内容をおさえる → 前後の関係（同じ内容／逆／原因と結果／例）で決める**。
- 接続語は A の3つの関係（同等・対比・因果）を示す目印である。

### S6 文章の構造（C 第2章、D UNIT15、B）
- 論説文は「筋道を立てて」書かれている。主張・理由・具体例・対比・反対意見（譲歩）という部品に分ける。
- 「たとえば」の後は具体例。具体例の前後に主張がある。
- 「〜ではなく、〜だ」「たしかに〜。しかし〜」の後ろに筆者の意見がある。
- 段落の要点 → 中心段落 → 中心文 → **削除（具体例・繰り返しを削る）と補足（指示語を戻す）**で要旨にする。

### S7 文学的文章の心情（C 第3章、D UNIT18〜22）
- 自分の思い込み（「泣く」＝悲しい）で読まない。**文脈**（前の出来事）から決める。
- 心情の根拠になるもの：①**出来事・状況** ②**心情語** ③**動作・表情・せりふ・情景**。
- 理由の型：〈出来事〉→だから→〈心情〉→だから→〈行動・発言〉。
- 心情の変化：**変化前の心情 ／ きっかけ ／ 変化後の心情**の3つの枠で整理する。
- 人物像：行動と言葉を複数集めて人柄を決める。
- 主題：起承転結の「転」（山場）で何が変わったかをまとめる。
- 随筆：〈体験談〉→〈感想・考え〉の構造。考えの部分は論説文に近い読み方をする。

### S8 記述の型（A 総合テスト、C、D）
- 対比型：「Aは〜だが、Bは〜」（観点をそろえる）。
- 理由型：「〜ので、〜から。」
- 言いかえ型：「〜ということ。」
- 字数指定（「○字以上○字以内」「句読点も一字に数える」）と、本文の語句を使うこと。

## 4. 誘導（足場かけ）の設計パターン

ご希望の「誘導付きの問題」は、資料の中で次の5種類の仕組みとして使われている。

1. **〈例〉にならって**（A 全体）
   最初に解き方を見せた例題を置き、同じ型の問題を続ける。例題の下に「こうした方法も、抽象化の方法の一つです」と、型の名前を書いて意識させる。
2. **★ここがポイント★**（A 全体）
   各見開きの右下にあるヒント欄。「④・⑤は、捨てるべき〈具体〉が二つに分かれています」のように、つまずく問題を名指しする。
3. **解き方✓1→✓2→✓3 の手順化**（D 全UNIT）
   例：指示語「✓1 傍線部のあとの内容をおさえる → ✓2 前から探す → ✓3 指示語に当てはめてみる」。
4. **手順をなぞる穴埋め＝「解き方チェック問題」**（D）
   同じ手順を、今度は生徒が穴埋めでたどる。（例：「✓1 傍線部のあとに（　）と書かれているのをおさえる」）。**前段階プリントの中心にできる形式**。
5. **整理図の空欄**（A Ⅳ、D）
   本文を因果の図・対比表・心情の3枠に整理させてから、最後の答えを書かせる。

**段階的に誘導を外していく流れ**（資料の構成から）
例題（解説つき）→ 手順なぞり（穴埋め）→ 同じ形式の実践問題（誘導なし、正答率つき）→ 総合問題（複数の形式が混ざる）。
→ サイトでは同じ形式のプリントを **誘導レベル 3／2／1／0** で出し分けられるとよい。

**解説の書き方**（C の解説がもっとも参考になる）
- 根拠になる本文を囲みで抜き出し、太字で強調する。
- 関係を記号で示す（「＝（イコール）」「⇔（対比）」「←だから」「↑なぜなら」）。
- 選択肢を一つずつ検証する（「アは『言葉だけで』が明らかに間違い」「ウは本文のどこにも書かれていません」）。
- 最後に**ルール名に戻す**（「〈読解の基本ルール〉をしっかり思い出してください」）。
- 「ここが大切」の囲みでルールを一文にまとめ、巻末に「解法のポイント一覧」（穴埋め式）を置く。

## 6. サイト設計への示唆

### データモデル案
- **問題**：`skill`（S0〜S8）、`format`（T1〜T21）、`scaffold_level`（0〜3）、`text_length`（単文／短文／段落／長文）、`genre`（説明的／文学的）、本文、設問、解答、解説（根拠箇所・関係図・選択肢の検証）
- **プリント**：問題の組み合わせ、問題用紙と解答・解説用紙を分けて出力

### 表示・印刷
- 国語の資料はすべて**縦書き**。CSS の `writing-mode: vertical-rl`、ルビ（`<ruby>`）、A4／B5 の印刷レイアウトが必要。
- 解答欄の種類：（　）型の書き込み欄、記号を書く□、**原稿用紙のマス目**（字数指定の記述）、ア→イ→ウの因果ボックス、表。
- 縦書きの中に入れる縦向きの矢印図（具体↑↓抽象、だから↓↑なぜなら）。

### 著作権の注意（重要）
資料の本文・設問・解説は市販の問題集のものなので、**サイトに転載するとそのまま公開することになる**。サイトで使うのは「形式」「誘導の仕組み」「スキルの分け方」だけにして、本文と設問は**オリジナルで作る**前提にするのが安全。T1〜T12 は単文〜短文で成り立つので、オリジナルの問題を量産しやすい（生成AIでの下書きも現実的）。

## 8. 追加資料の分析（読解の基礎・出題パターン型の問題集）

**構成**：〔理解編〕例題でまなぶ → 要点のまとめ（ポイント１・２）→ 確認問題（配点つき・100点満点）→ 実戦問題（標準）→「出題パターン」（例題・解法のルール・解答図 → 入試実例）。

### 説明的文章で新しく取り入れる観点
| 単元 | 内容 | サイトへの反映 |
|---|---|---|
| 文脈をとらえる | 接続語の位置（文節と文節／文と文／段落と段落）、指示語は直前→ないときだけ後ろ、置き換えて確かめる | ステージ４で対応済み |
| 要点をとらえる | 段落の**中心文**と**付加文**（具体例・補足）を分ける。中心文は段落の初めか終わり。文末表現（〜なければならない・〜ではないだろうか）に注目。**キーワード**＝全文で繰り返される語句／段落内で新しく出てくる語句 | **5-4 を新設** |
| 段落構成をとらえる | 段落の役割（話題提示・具体例・対比・言いかえ・まとめ）、**意味段落**に分ける、序論・本論・結論／起承転結、「ところで」で論が変わる | **5-5 を新設** |
| 要旨をとらえる | 意味段落ごとの話題→結論の段落→他の段落の必要部分を補う | 5-2 で対応済み |
| 出題パターン | ①言い換え：**部分と部分を対応させる**・結びの言葉を対応させる　②対義語・対比表現で関係を整理　③**裏返しの表現**：答えが直接書かれていないときは、間接（逆）の表現を裏返して直接表現に直す　④**比喩**：似た働きをする物・事柄を対応させる | ③④を **5-6 として新設** |

### 文学的文章で新しく取り入れる観点
| 単元 | 内容 | サイトへの反映 |
|---|---|---|
| 場面・情景 | **時・所・人物**の変化で場面を分ける。情景描写が心情の変化と関連する | **6-4 を新設** |
| 会話の流れ | 会話文の空欄補充（だれのせりふか、前後の受け答えから決める） | **6-5 を新設** |
| 出題パターン | ①空欄（様子を表す言葉）は前後の文脈に注目　②情景のイメージ（比喩をつかむ→場面の情景をつかむ）　③人物像（様子→行為）　④随筆「何が言いたいの？」（内容を整理→筆者の言いたいことをつかむ） | ①を 6-5、④を **6-6（随筆）として新設** |

### 形式面
- 確認問題・実戦問題に**配点と得点欄（／100）**がある → ステージ７の実戦問題に配点と得点欄を追加。
- 「解答図」：本文の部分と答えの部分を線で結んで対応を示す → 新設プリントの解説で、対応表の形で使う。
