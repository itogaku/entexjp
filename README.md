# 読解ステップ（公立高校入試・国語 読解プリント）

中学3年生向け。文章読解の「解く前に身につけたいこと」を、基礎から入試レベルまで段階的に練習する印刷用プリント集です。

- `index.html` … プリント一覧（ブラウザで開く）
- `print.html?id=1-2` … 1枚ずつ印刷／`print.html?stage=1` … ステージまとめて印刷（「誘導なし（自力で解く版）」も選べる）
- `bank.html` … 問題バンク。技能別257問・長文大問20題・答案改善24問（読解プリントメーカー v86 のデータ、`data/bank.js`）から選び、「自力で解く」または「自力 → 誘導 → 再挑戦」の形でプリントを作る
- 印刷設定：A4・横向き／余白なし／倍率100％／背景のグラフィックをオン（Chrome・Edge 推奨）

サーバー不要（ファイルを直接開いて使えます）。フォントは Google Fonts（BIZ UD明朝・BIZ UDPゴシック）を読み込みます。

## ステージ構成
| ステージ | 内容 |
|---|---|
| 0 | 読解の大原則（本文に書いてある／食い違う／書いていない、選択肢の吟味、主語、事実と推測） |
| 1 | 言いかえる（抽象と具体） |
| 2 | くらべる（対比・観点・譲歩） |
| 3 | たどる（因果・かくれた理由・「〜から。」） |
| 4 | 指示語と接続語・脱落文挿入 |
| 5 | 説明的文章の組み立て（文の役割・中心文とキーワード・段落構成・要旨・傍線部説明・裏返しの表現と比喩・図表・話し合い） |
| 6 | 文学的文章（心情・心情の変化・人物像・場面と情景・会話の流れ・随筆・表現の効果） |
| 7 | 設問分析・選択肢のずれ・答案改善、入試形式の実戦問題５題（説明的文章２・文学的文章２・随筆、誘導なし・配点つき）、読解ルールのまとめ |

ステージ別プリントの本文・設問はオリジナルです（市販の参考資料からは、形式と誘導の仕組みだけを取り入れています）。問題バンクの問題は「読解プリントメーカー v86」から移したものです。

## プリントの追加方法
`data/stageN.js`（または練習用の `data/extra1〜3.js`）に `Yomi.register({...})` を追加します。部品（`assets/js/yomi.js` の `Yomi.h`）：

- `B(文字数, 答え)` 書き込み欄　`K(答え)` 記号欄　`G(字数, 答え, 一行の字数)` 原稿用紙　`L(行数, 答え)` 罫線欄
- `CH([選択肢...], 正解)` 選択肢　`BO(文, '①')` 傍線　`S('Ａ', 答え)` 本文中の空欄
- `POINT` 要点　`EX` 例題　`Q` 問題　`HINT` ヒント　`STEPS` 手順　`FLOW` 流れ図　`TBL` 表　`GRID` 二段組　`KAI` 解説

答えは解答版で赤字表示されます。用紙からあふれると自動で次の用紙に送られ、それでも収まらない場合は印刷画面の上部に警告が出ます。
