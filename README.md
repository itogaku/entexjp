# 読解ステップ（公立高校入試・国語 読解プリント）

中学3年生向け。文章読解の「解く前に身につけたいこと」を、基礎から入試レベルまで段階的に練習する印刷用プリント集です。

全体は四段構成です。最初に**診断テスト**で、どこから始めるかを決めます。中学生用は D-1（はじめ）・D-3（中間）・D-5（まとめ）、小学生用は D-2・D-4・D-6 です。三つは区分と配点が同じなので、得点で伸びを比べられます（`data/diag.js`・`data/diag-chu.js`・`data/diag-sho.js`）。

0. **小学生「読みとり」**（`bank.html?kind=kids&band=12|34|56`）… 小１・２／小３・４／小５・６の三つ（各八技能×六題）。漢字は文部科学省「学年別漢字配当表」（令和二年度から）で、その学年までに習う字だけを使い、その学年で新しく習う字にはふりがなをつける（小１・２はすべての漢字）。解説は問いごとの子ども向けの文（`ex`）で、同じ漢字のきまりに合わせてある。データでは「研究《けんきゅう》」「二十字｜以内《いない》」と書く（`data/kids.js`）。小１・２の★は分かち書き。学年ごとに文字の大きさを変えて印刷。
   - **技能別の練習（小学生版）**（`bank.html?kind=skillk&band=34|56`）… 中学「入門」の二八七問を小学生向けにやさしくした版（`data/bank-kids.js`）。★１・２→小３・４、★３・４→小５・６。漢字のきまりは上と同じ。
   - **書く練習**（`bank.html?kind=write&band=34|56|chu`）… つなぎ言葉の穴うめ・二つの文を一つにする・主語と述語をそろえる・ならべかえ・理由を書く・例をあげる／まとめる・続きを書く・要点の空らんうめ（八技能×四題×三つの学年＝九十六題、`data/write.js`）。本文の空らんは〔Ａ〕と書く。中学版は入門の画面から。
1. **入門「文章に慣れる」**（`bank.html`）… 中学生向け。やさしく短い文章で、技能ごとに読む練習をします。本編の前の準備や、読むのが苦手な生徒のくり返し練習用です（`data/bank.js`・`data/bank-plus.js`、答案を直す練習を含む）。入試でよく出る形（語句の意味・二つの文章・段落の順序・事実と意見・表現技法・主題・象徴・条件記述）の三十五問は `data/bank-plus2.js`。
2. **本編「解き方を学ぶ」**（`print.html`）… ステージ０〜７のプリントで、入試で使う解き方を段階的に学びます（`data/stageN.js`）。
3. **仕上げ「入試演習」**（`bank.html?kind=big`）… 入試と同じ形式の長文の大問35題（b21 二つの文章と表、b22 表現技法・象徴、b23 段落の順序・事実と意見、b24 資料と本文、b25 話し合いと本文、b26 推移の表と意見文、b27〜b32 古文、b33〜b35 漢文）。本文中の「【表】」の次の、全角空白で区切った行は表として印刷。
4. **作文**（`print.html?id=S-1`〜`S-8`、`data/sakubun.js`）… 原稿用紙の使い方と作文の型・主張・理由と体験・条件作文・資料を読んで書く・二つの意見を比べる・推敲・入試形式の模擬（採点基準つき）。原稿用紙の答えの「\n」は改段落。配点（合計100点）・採点基準・解説つき。
5. **古典**（`print.html?stage=K`、`data/koten-bun.js`・`koten-doku.js`・`koten-kan.js`）… 解き方のプリント K-1〜K-10。歴史的仮名遣い・古語の意味・係り結び・主語（動作主）・会話文の範囲・現代語訳との対応・主題・和歌と俳句・返り点と書き下し文・漢詩と漢文の主題。仕上げは入試演習の古文（b27〜b32）・漢文（b33〜b35）。漢文は「字(送り仮名)[返り点]」と書く（例：`学(ビテ)而時(ニ)習(フ)[レ]之(ヲ)`）。プリントでは `Yomi.h.KAN(lines)`、入試演習の本文では「＃」で始まる行が漢文になる。

- `index.html` … 一覧（左で「入門／ステージ０〜７／入試演習」を切りかえる）
- `print.html?id=1-2` … 1枚ずつ印刷／`print.html?stage=1` … ステージまとめて印刷（「誘導なし（自力で解く版）」も選べる）
- `bank.html` … 問題を選んでプリントにする（「自力で解く」または「自力 → 誘導 → 再挑戦」）。URL：`?skill=指示語&level=12&mode=guided&auto=5`（入門の指示語を★１・２から５問、誘導つきで自動作成）、`?kind=big&pick=b7`（入試演習の大問を１題）、`?kind=kaizen`（答案を直す練習）
- 印刷設定：A4・横向き／余白なし／倍率100％／背景のグラフィックをオン（Chrome・Edge 推奨）

サーバー不要（ファイルを直接開いて使えます）。フォントは Google Fonts（BIZ UD明朝・BIZ UDPゴシック）を読み込みます。

## ステージ構成
| ステージ | 内容 |
|---|---|
| 0 | 読解の大原則（本文に書いてある／食い違う／書いていない、選択肢の吟味、主語、事実と推測） |
| 1 | 言いかえる（抽象と具体） |
| 2 | くらべる（対比・観点・譲歩） |
| 3 | たどる（因果・かくれた理由・「〜から。」） |
| 4 | 指示語と接続語・脱落文挿入・語句の文脈上の意味 |
| 5 | 説明的文章の組み立て（文の役割・中心文とキーワード・段落構成・要旨・傍線部説明・裏返しの表現と比喩・図表・話し合い・二つの文章の比較・段落の並べかえと事実／意見） |
| 6 | 文学的文章（心情・心情の変化・人物像・場面と情景・会話の流れ・随筆・表現の効果・表現技法・主題と象徴） |
| 7 | 設問分析・選択肢のずれ・答案改善・条件つき記述、入試形式の実戦問題５題（説明的文章２・文学的文章２・随筆、誘導なし・配点つき）、読解ルールのまとめ |

ステージ別プリントの本文・設問はオリジナルです（市販の参考資料からは、形式と誘導の仕組みだけを取り入れています）。練習問題は「読解プリントメーカー v86」から移した問題（`data/bank.js`）と、ステージ２・５の技能のために同じ形式で追加した問題（`data/bank-plus.js`）です。

入門の問題は、文章に慣れることを目的に、やさしい言葉・短い文・身近な場面に書き直しています（★１〜★４）。入試演習の長文は入試の大問形式で、記述に加えて記号選択と抜き出しを含み、各問に配点（合計百点）・採点基準（部分点）・解説が付いています。

## プリントの追加方法
`data/stageN.js` に `Yomi.register({...})` を追加します。部品（`assets/js/yomi.js` の `Yomi.h`）：

- `B(文字数, 答え)` 書き込み欄　`K(答え)` 記号欄　`G(字数, 答え, 一行の字数)` 原稿用紙　`L(行数, 答え)` 罫線欄
- `CH([選択肢...], 正解)` 選択肢　`BO(文, '①')` 傍線　`S('Ａ', 答え)` 本文中の空欄
- `POINT` 要点　`EX` 例題　`Q` 問題　`HINT` ヒント　`STEPS` 手順　`FLOW` 流れ図　`TBL` 表　`GRID` 二段組　`KAI` 解説

答えは解答版で赤字表示されます。用紙からあふれると自動で次の用紙に送られ、それでも収まらない場合は印刷画面の上部に警告が出ます。

## 記述の字数のきまり

記述問題は「指定字数の八割以上を書く」きまりに合わせてある。模範解答は指定字数の八割以上〜十割で、解答欄（原稿用紙）は指定字数のマス数になる。字数を変えたり問題を足したりするときは、このきまりを守る（「〜字以上〜字以内」の問いは対象外）。抜き出しは「〇字で」と字数をぴったりにする（「最初の五字」を書かせる問いも、抜き出す部分の字数ぴったり）。
